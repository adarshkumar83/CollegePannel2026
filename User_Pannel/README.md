# User_Pannel

Read-only student view of the exams created in Admin_College.
React + Vite, Bootstrap, Axios.

```bash
npm install
npm run dev
```

Open http://localhost:5174. The backend (`Api_College`) must be running on http://localhost:5000.
To use another API address, create `.env` with `VITE_API_URL=http://your-server/api`.
